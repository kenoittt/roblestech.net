# For humans

Things only a person can do, for any app in the repository: a setting in an account, an update on the live database, a decision. Each page says what to do, why, and how, in plain words. When a task needs one of these, add it to the right page, mention it in the pull request, and tell the person you're working with.

**How a message reaches someone:** every Claude session reads its person's page here when it starts, and tells them what's waiting (the repository's `CLAUDE.md`, rule 10). So a note on Kenneth's page reaches Kenneth, through his Claude, even if he never opens this folder.

Kenneth owns the accounts and the infrastructure (GitHub, Vercel, Supabase, Microsoft 365, the domain, its DNS and hosting), so most of these land on his page.
