# For humans

Things only a person can do, for any app in the repository: a setting in an account, an update on the live database, a decision. Each page says what to do, why, and how, in plain words. When a task needs one of these, add it to the right page and mention it in the pull request.

Kenneth owns the accounts and the infrastructure (GitHub, Vercel, Supabase, Microsoft 365, the domain, its DNS and hosting), so most of these land on his page.

| Page | For | What |
|---|---|---|
| [kenneth.md](kenneth.md) | Kenneth | His open items, in order |

An app can keep its own how-to pages for people too, like the PPM's guide to [giving the team accounts](../../ppm/docs/for-humans/giving-the-team-accounts.md).
