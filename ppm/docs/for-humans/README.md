# For humans

Things only a person can do: a setting in an account, a database update on the live project, a decision. Each page says what to do, why, and how, in plain words. When a task needs one of these, add or update the person's page in the repository's [`docs/for-humans/`](../../../docs/for-humans/README.md), mention it in the pull request, and tell the person you're working with. Each Claude session reads its person's page when it starts, so the message reaches them.
