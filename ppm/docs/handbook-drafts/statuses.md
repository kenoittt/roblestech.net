# What each status means

> Draft for the in-app Handbook, shelf "Using the PPM". Written during the build as sample content (2026-10-01) and saved here on 2026-10-03. Some features came after it (repeating tasks, moving calendar blocks, an admin signing off in someone's place, sign-off requests going to the people the rule names), so check it against the app before publishing.

*Six statuses, one rule each, so everyone reads a board the same way.*

Every task has one status. Each one answers a single question: where is this work right now?

| Status | Means | Move it here when |
|---|---|---|
| **Backlog** | Worth doing, not planned yet | You capture an idea or a request |
| **Todo** | Planned and ready to start | It has an owner and you mean to do it soon |
| **In progress** | Someone is working on it | You start |
| **In review** | Done, waiting for a check | You need someone to look before it counts |
| **Done** | Finished and accepted | The work is complete |
| **Cancelled** | Not doing it | Plans changed; the history stays |

## A few habits that keep the board honest

- Keep **In progress** small. If you have more than three, finish one first.
- Move a task to **In review** when someone else signs it off. Their name goes in the Reviewer field, and they get a notification.
- Never delete work you did. Cancel it instead, so the history stays.
